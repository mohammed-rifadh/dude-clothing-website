# Dude Clothing Website 👕
### Full-Stack E-Commerce Web Application

Dude Clothing Website is a full-stack clothing e-commerce project built to provide a modern online shopping experience. It demonstrates practical skills in frontend development, backend API development, and database integration.

## ✨ Features

- Modern clothing website user interface
- Product listing and product information
- Category-based product retrieval
- RESTful API integration
- Backend development using ASP.NET Core Web API
- Relational database integration using Microsoft SQL Server

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm
- .NET SDK
- Microsoft SQL Server

### Clone the Repository

```bash
git clone https://github.com/mohammed-rifadh/dude-clothing-website.git
cd dude-clothing-website
```

### Run the Frontend

```bash
cd dude-clothing-frontend
npm install
npm run dev
```

Open the local URL displayed by Vite in your browser.

### Run the Backend

Open another terminal from the repository root:

```bash
cd DudeClothing.Api/DudeClothing.Api
dotnet restore
dotnet run
```

Configure your local database connection string and frontend API URL before running the complete application.

## 🔒 Security

- Keep database credentials and API keys out of GitHub.
- Use local development settings for private configuration.
- Configure production secrets securely.
